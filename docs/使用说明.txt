艾派互联 客户端（Windows）
====================================

一、运行
1. 双击 艾派组网.exe。
2. 首次运行会弹出“用户账户控制”，点“是”
   （创建虚拟网卡和局域网广播需要管理员权限，属正常现象）。

二、登录
1. 打开软件只显示登录/注册窗口，服务器地址已内置，无需填写。
2. 没有账号就点“注册”，有账号直接“登录”。
   一个账号最多同时登录 5 台设备。

3. 软件内自带更新：到“设置”页可以看到当前版本，点“检查更新”即可
   直接升级到新版本（自动下载、校验、替换并重启，不用手动安装）。
   登录后也会自动检查一次，有新版本会弹出提示。

三、组网
1. 创建组网：填名称 → 点“创建组网”，会得到一个 8 位适配码。
2. 加入别人组网：输入适配码 → 点“加入组网”。
   不同账号输入同一个适配码，都会连到同一组网（各自分配不同虚拟IP）。
3. 选中组网双击（或到“组网连接”页点“一键连接”）。
4. 虚拟 IP 是固定的：同一台设备在同一个组网里只分配一次虚拟 IP，
   重连、断开、退出后再加入，拿到的都是同一个 IP，
   只要不删除组网就不会变（列表上方会显示“本机固定IP”）。
5. 连接后可在“组网连接”页看到每个对端的链路类型：
   - P2P直连：最优，数据不过服务器
   - 中继：打洞失败，走服务器转发
   程序按延迟自动择优，无需手动切换。
6. 组网列表上方会显示连接状态：“● 已连接：组网名”是已接入组网，
   “○ 未连接”表示还没连上；成员状态里的“在线/离线”按真实链路显示。

四、游戏联机
1. 开服机启动游戏服务端，监听 0.0.0.0（或组网虚拟 IP）即可，
   不需要在路由器上做任何端口映射，组网内成员之间所有端口互通。
2. 朋友在游戏里“直接连接 / 输入IP”，填开服机的虚拟 IP + 游戏端口。

五、文件 / 打印机共享
1. 在“共享”页点“一键配置共享环境”（自动设置专用网络并放行共享防火墙）。
2. 需要局域网搜房/网上邻居可见时，勾选“局域网广播中继”，重连组网后生效。
3. 共享本机内容（给队友用）：在“本机共享”里直接点
   “+ 文件夹”“+ 磁盘”“+ 打印机” → 选好目标、填个共享名即可。
   创建成功后会自动显示并可复制访问地址（\\你的虚拟IP\共享名）。
4. 免密共享（推荐先开）：点“开启免密共享”，会自动创建一个专用共享账号，
   并放开来宾访问。之后队友不管你共享的是文件夹、整盘还是打印机，
   都不用输密码就能访问；再点一次就是关闭。
   （想改账号密码用旁边的“改共享账号”，两台电脑要用同一套才会自动带上）
5. 用队友的共享（最省事）：点共享页的“组网内共享”，
   会列出组网里所有队友共享出来的文件夹和打印机：
   - 选中文件夹 → 点“映射到本地”，自动分配盘符，打开“此电脑”就能看到
   - 选中打印机 → 点“连接打印机”，直接装到本机
   - 也可以点“打开”直接浏览，或双击列表项快速映射
   也可以手动填地址：把对方发来的 \\虚拟IP\共享名 粘到“映射网络驱动器”，
   选盘符点“映射”。
6. 常用操作：
   - 复制地址：把 \\虚拟IP\共享名 发给队友
   - 打开：直接在本机打开该共享
   - 取消共享 / 断开所选映射：撤销上面的操作
   详细图文步骤见官网教程：https://net.appiie.cn/?p=gongxiang

六、目录说明
- engine/           EasyTier 引擎（LGPL-3.0，见 engine/LICENSE）
- settings.json     生成于 %APPDATA%\艾派组网\，保存登录状态

注意：engine 目录不可删除；请勿向陌生人透露适配码和登录信息。
